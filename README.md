# Smart Access Control System

## Dependencies

This project uses [Dlib_face_recognition_from_camera](https://github.com/coneypo/Dlib_face_recognition_from_camera) by coneypo for face recognition. It is not included in this repository (its model files exceed GitHub's file size limits).

To use it, clone it into the project root:

```bash
git clone https://github.com/coneypo/Dlib_face_recognition_from_camera.git
```
